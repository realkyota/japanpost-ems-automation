# 日本郵便 EMS 送り状作成の自動化

macOS 上で Python と Playwright を使い、国際郵便マイページの EMS（物品）送り状作成を補助する個人プロジェクトです。日本郵便の公式ツールではありません。

[English](README.md) · [中文操作说明](docs/usage.zh-CN.md)

## 主な機能

- macOS キーチェーンによる任意のログイン情報保存、または手動ログイン。
- 選択済みの差出人を保持し、JSON から受取人と内容品1件を入力。
- EMS（物品）の選択、原産国の選択、内容品の確定。
- 発送予定日は起動日の日本時間を基準に翌日を選択。
- 前回データの確認画面、別ウィンドウ、画像ボタンへの対応。
- 登録前の入力ハッシュ保存による重複作成の抑制と診断情報の出力。
- 公式の「注意事項に同意して送り状を印刷」をクリックした時点で自動操作を終了。

## 実行方法

Python 3.10 以上と Playwright が動作する macOS が必要です。ターミナルの表示は現在中国語です。

```bash
# 任意：ログイン情報をキーチェーンに保存
bash setup_login.command
# JSON ファイルを選択して実行
bash run.command
# パスを指定して実行
bash run.command /path/to/Recipient_Name.json
# 登録前の確認画面で停止
bash run.command /path/to/Recipient_Name.json --stop-before-register
```

初回は依存ライブラリと Chromium をダウンロードします。サンプル JSON は架空情報であり、そのままでは出力できません。別ファイルにコピーし、実際の情報を設定して `_example` を削除してください。金額・重量・数量・電話番号などは文字列で指定します。

スクリーンショットや文章から JSON への変換は別工程です。本プログラム自体に OCR 機能はありません。内容品、金額、原産国、HS コード、贈物・販売品の区分は実物に合わせて指定してください。公開版に個人用の内容品初期値はありません。原産国は JSON に明示し、必要な HS コードを指定してください。サンプルの氏名・住所・金額・重量は架空の値です。HS コード 000000 はテスト用のダミー値であり、申告には使用できません。危険物に関する申告は実際に確認したうえで設定してください。

## 登録と個人情報

`output/run-state.json` は登録を試みた記録であり、登録成功の証明ではありません。中断後は公式の発送予定データで確認してから再実行してください。更新時も記録を保持してください。

認証情報はキーチェーンに保存します。実際の受取人 JSON、実行記録、PDF、画面画像は公開対象から除外しています。印刷ボタンを押した後の印刷操作は利用者が行い、完了後にターミナルで Enter を押すとブラウザーが閉じます。

## 検証と開発

```bash
python3 -m pip install -r requirements.txt
python3 -m unittest discover -v
node test_login.cjs
node test_content.cjs
node test_dispatch.cjs
```

モックと DOM フィクスチャによるオフラインの回帰テストです。CI は実アカウントへのログインや実際の発送登録を行いません。サイト変更や認証、配送条件によって手動対応が必要です。

AI の支援を受けて開発しました。プロジェクト所有者が要件・実際の作業手順を定義し、macOS で動作を確認して不具合を報告し、改善を重ねた業務自動化の実例です。
